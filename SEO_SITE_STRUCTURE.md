# Tenant Reply — Canonical SEO Site Structure

Preserve the existing ecosystem-wide navigation exactly. This is the SEO/content hierarchy beneath that shell.

## Public
- `/` — Tenant Reply pillar: respond to landlords, property managers, eviction and housing notices; explain the problem plainly; show how AI handles the heavy lifting; feature common workflows; clear review-before-send CTA.
- `/workflows` — scalable workflow discovery hub with search, suggested searches, category browsing, and premium workflow cards with a consistent image area.
- Individual workflow authority pages — one page per search intent, with unique explanation, what to gather, what AI handles, what the user reviews, FAQ, related workflows, and a direct handoff into the reply workflow.
- `/how-it-works` — upload notice/documents → AI understands → organize facts/evidence → build reply → review/approve → MailMyPDF sends → track/preserve proof.
- `/products`, `/pricing`, `/mail-a-pdf` — ecosystem/product pages.
- `/about`, `/contact`, `/faq`, `/resources/*` — supporting SEO/footer content.
- `/privacy`, `/terms`, `/404` — legal/error.

## Workflow taxonomy
Eviction & possession; rent & fees; repairs & habitability; landlord/property disputes; deposit & move-out; tenant rights; general tenant responses.

## Discovery standard
The hub is search-first as the catalog grows. Users should be able to search by notice, lease issue, landlord action, property problem, or desired outcome without knowing the workflow name. The homepage may feature 4–8 high-value workflows, while `/workflows` remains the complete directory.

## Workflow card standard
Every workflow card uses the shared ecosystem anatomy: top image placeholder, category, strong serif title, concise problem-focused description, useful search-intent context, and clear CTA. Relevant imagery can replace the placeholder later without changing the layout.

## SEO flow
Pillar → workflow hub → authority page → authenticated reply workflow. Preserve existing workflow URLs and use intent-specific pages rather than thin keyword variants.

## Simplicity rule
AI handles notice/lease analysis, facts, deadlines, issues, evidence organization, tenant-rights analysis, strategy, drafting, validation, recipient checks and mailing preparation underneath a short user-facing flow.

## Navigation and typography lock
Do not add vertical-specific menu items. Use the existing MailMyPDF ecosystem shell and shared typography hierarchy.
